# CapaBot

CapaBot is an AI-powered resume analysis tool that compares a candidate’s resume with a given job description and generates a match score along with a detailed skill analysis.

## 📌 Features
- Resume vs Job Description similarity score  
- Essential & missing skill identification  
- TF-IDF-based text analysis  
- Gemini-Pro contextual understanding  
- Simple and fast interface  
- No login required  

## 🛠 Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Python  
- **AI Models:** TF-IDF, Gemini Pro  
- **Tools:** Git, GitHub, VS Code  

## 🚀 How to Run
1. Clone the repository:
git clone https://github.com/aravindadityxa/capabot.git

2. Navigate to the project directory:
cd capabot

3. Install dependencies:
pip install -r requirements.txt

4. Run the application:
python app.py
